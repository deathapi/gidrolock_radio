# Радиопротокол Gidrolock 868 МГц

Описание радиопротокола датчиков протечки **WSR**, **WSR.LONG** и беспроводного пульта управления кранами **SENSO 9003**.

## Параметры радиоканала

| Параметр | Значение |
|---|---|
| Частота | **867.84 МГц** |
| Модуляция | **FSK** |
| Скорость | **2268 бит/с** |
| Период бита | **440.95 мкс** |
| Девиация | **±90.01 кГц** |
| Порядок битов | MSB first |
| Кодирование | нет |

## Формат кадра

Все значения ниже шестнадцатеричные. Наблюдаемый эфирный кадр:

| Преамбула | Синхромаркер | Класс | ID устройства | Данные | Контрольная сумма |
|---|---|---|---|---|---|
| `AA AA AA AA` | `2D D4` | `CLS` | `ID0 ID1 ID2` | `B0 B1 B2` | `SUM` |

После `2D D4` следует логический кадр длиной 8 байт:

| Поле | Размер | Назначение |
|---|---:|---|
| `CLS` | 1 байт | класс устройства |
| `ID0..ID2` | 3 байта | постоянный ID устройства в порядке передачи |
| `B0` | 1 байт | событие или команда класса |
| `B1` | 1 байт | состояние батареи для описанных устройств |
| `B2` | 1 байт | модель устройства |
| `SUM` | 1 байт | контрольная сумма `sum8` |

Байт класса в контрольную сумму не входит:

```text
SUM = sum8(ID0, ID1, ID2, B0, B1, B2)
    = (ID0 + ID1 + ID2 + B0 + B1 + B2) & 0xFF
```

Класс является частью идентификатора: полный ключ устройства имеет вид `[CLS, ID0, ID1, ID2]`.

## Устройства и модели

| Устройство | `CLS` | `B2` |
|---|---:|---:|
| Датчик протечки WSR | `01` | `20` |
| Датчик протечки WSR.LONG | `01` | `21` |
| Пульт управления кранами SENSO 9003 | `02` | `0B` |

## Пакеты

| Устройство | `CLS` | `B0` | Значение | Период передачи |
|---|---:|---:|---|---|
| WSR / WSR.LONG | `01` | `01` | обнаружена протечка | каждые 2–5 с, пока датчик мокрый |
| WSR / WSR.LONG | `01` | `04` | сухо / keepalive | после высыхания каждые 6–7 с около минуты; в покое примерно раз в 4 часа |
| SENSO 9003 | `02` | `00` | включение питания пульта | один раз при запуске |
| SENSO 9003 | `02` | `06` | открыть краны | при нажатии кнопки |
| SENSO 9003 | `02` | `07` | закрыть краны | при нажатии кнопки |

Для всех трех устройств:

- `B1.bit0 = 1` означает низкий заряд батареи;
- в нормальном состоянии наблюдается `B1 = 00`;
- назначение остальных битов `B1` неизвестно, поэтому проверять следует только маску `B1 & 0x01`.

## Примеры

В примерах используются условные ID устройств.

### WSR: штатный keepalive

```text
AA AA AA AA 2D D4 01 12 34 56 04 00 20 C0
```

```text
SUM = sum8(12, 34, 56, 04, 00, 20) = C0
```

### SENSO 9003: пакет при включении

```text
AA AA AA AA 2D D4 02 65 43 21 00 00 0B D4
```

```text
SUM = sum8(65, 43, 21, 00, 00, 0B) = D4
```

## Примечания

- `AA` — байт преамбулы.
- `2D D4` — синхромаркер протокола.
- `sum8` предназначена для обнаружения ошибок передачи.
